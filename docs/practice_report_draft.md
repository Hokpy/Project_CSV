## 1. Введение

В ходе производственной практики ПП.02.01 выполнена разработка программного модуля для импорта товаров интернет-магазина из файлов формата CSV. Проект реализован в виде веб-приложения на платформе ASP.NET Core MVC с использованием языка программирования C#.

Вариант задания — **Электроника**. Модуль поддерживает специфические поля для данной категории товаров: бренд производителя, срок гарантийного обслуживания и номер модели.

## 3. Техническое задание

### 3.1. Общее описание

Необходимо разработать модуль `ECommerceCsvImport` — веб-приложение ASP.NET Core MVC, обеспечивающее:

- Загрузку CSV-файлов с товарами через веб-интерфейс.
- Валидацию данных каждой строки по заданным правилам.
- Сохранение корректных записей в оперативной памяти (in-memory хранилище).
- Вывод результатов импорта: количество успешных записей, список ошибок.
- Просмотр импортированных товаров в виде таблицы.

### 3.2. Формат входных данных

Файл CSV должен содержать заголовок:

```
sku,name,description,price,currency,category_name,stock,image_url,is_active,brand,warranty_months,model_number
```

### 3.3. Правила валидации

| Поле | Тип | Ограничения |
|------|-----|-------------|
| `sku` | string | Обязательно, уникально |
| `name` | string | Обязательно |
| `price` | decimal | > 0 |
| `currency` | string | Непустое значение; пустое нормализуется в `RUB` |
| `stock` | int | ≥ 0 |
| `is_active` | bool | true, false, 1 или 0 |
| `brand` | string | Обязательно |
| `warranty_months` | int | 0–60 |
| `model_number` | string | Необязательно |

### 3.4. Дополнительные требования варианта «Электроника»

- Поле `brand` является обязательным.
- Поле `warranty_months` должно содержать целое число в диапазоне от 0 до 60 месяцев включительно.
- Поле `model_number` может быть пустым.

## 4. Проектирование системы

### 4.1. Архитектура

Приложение построено по шаблону **MVC (Model-View-Controller)**:

- **Model** — классы данных и бизнес-логика: `Product`, `ImportResult`, `ImportError`.
- **View** — HTML-шаблоны Razor: форма импорта, список товаров.
- **Controller** — `ProductsController`: обработка HTTP-запросов, вызов сервисов.

Бизнес-логика вынесена в сервисный слой:

- `IProductRepository` / `InMemoryProductRepository` — хранилище товаров.
- `CsvLineParser` — упрощённый парсинг строки CSV с поддержкой кавычек, запятых внутри полей и экранированных двойных кавычек.
- `IProductImportService` / `ProductImportService` — оркестрация импорта и валидации.

### 4.2. Диаграмма классов (упрощённая)

```
ProductsController
    ├── IProductImportService
    │       └── ProductImportService
    │               ├── CsvLineParser
    │               └── IProductRepository
    │                       └── InMemoryProductRepository
    └── IProductRepository
```

### 4.3. Сервисная регистрация

Оба сервиса зарегистрированы как singleton в `Program.cs`:

```csharp
builder.Services.AddSingleton<IProductRepository, InMemoryProductRepository>();
builder.Services.AddSingleton<IProductImportService, ProductImportService>();
```

## 5. Реализация

### 5.1. Технологический стек

| Компонент | Технология |
|-----------|------------|
| Платформа | .NET 10.0 |
| Фреймворк | ASP.NET Core MVC |
| Язык | C# 13 |
| Хранилище | In-memory (List<Product>) |
| Тестирование | xUnit 2.9 |
| Система сборки | MSBuild / dotnet CLI |
| Контроль версий | Git |

### 5.2. Ключевые решения

**Парсинг CSV.** Реализован собственный упрощённый парсер `CsvLineParser`, поддерживающий поля в двойных кавычках, запятые внутри полей и экранирование кавычек удвоением (`""`). Полная поддержка многострочных RFC 4180-полей в рамках учебного задания не требуется.

**Валидация.** Все проверки сосредоточены в методе `ProductImportService.ImportFromLines`. При обнаружении любой ошибки в строке она пропускается целиком, в результат добавляется запись об ошибке с номером строки и описанием.

**Дубликаты SKU.** При попытке импортировать товар с артикулом, уже существующим в хранилище, строка пропускается с ошибкой «Артикул товара уже существует».

**Загрузка файла.** Контроллер принимает CSV через `IFormFile`, разрешает только расширение `.csv`, ограничивает размер файла 5 МБ и не принимает произвольные пути файловой системы сервера.

### 5.3. Структура проекта

Проект разбит на два проекта в одном solution:

- `src/ECommerceCsvImport` — основное MVC-приложение
- `tests/ECommerceCsvImport.Tests` — xUnit тесты
