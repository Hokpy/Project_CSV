## Фактическая HTTP smoke-проверка приложения

Приложение запущено на `http://127.0.0.1:5245`. Проверены:

- `GET /Products` — страница списка товаров открывается;
- `GET /Products/Import` — форма импорта открывается;
- `POST /Products/Import` с `sample_products.csv` — импорт 11 товаров;
- `POST /Products/Import` с `invalid_price.csv` — показана ошибка цены;
- `POST /Products/Import` с `duplicate_sku.csv` — показана ошибка дубликата SKU;
- `POST /Products/Import` с `empty_file.csv` — показано отсутствие данных;
- `POST /Products/Import` с `bad_active.csv` — показана ошибка `is_active`.

Итог: 7 из 7 HTTP smoke-проверок завершились ожидаемым результатом. Для четырёх тестовых файлов из `tests/ECommerceCsvImport.Tests/testdata/` использовались абсолютные пути, поскольку они не являются файлами `wwwroot/csv`.
